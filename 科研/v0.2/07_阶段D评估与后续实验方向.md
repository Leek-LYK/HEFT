# 阶段 D 评估结果与下一步实验方向

日期：2026-10-05（北京时间）。本轮检查复用已自动执行的完整验证，另做固定状态动作敏感性与冻结策略梯度诊断；没有启动新的训练或更新模型参数。

## 核心结论

D 完成 100 轮 critic 预热 + 500 轮 PPO，共 39,321,600 transitions。完整验证为 500 条动作、83 个家族 × 六路，共 3,000 条记录。C/D checkpoint 摘要、动作集合、数据版本和环境配置已核对。

六路平均成功率从 C 的 93.5% 降到 D 的 81.3667%，减少 364 个成功的路由-动作组合。D 门槛未通过，保留 C 作为当前性能基线。

| 路径 | C 成功率 | D 成功率 | 差值（百分点） | D 完成比例 |
|---|---:|---:|---:|---:|
| human->g1 | 93.2% | 71.8% | -21.4 | 86.44% |
| g1->g1 | 94.8% | 76.0% | -18.8 | 88.36% |
| roban->g1 | 95.8% | 74.2% | -21.6 | 87.77% |
| human->roban | 90.8% | 85.8% | -5.0 | 93.92% |
| g1->roban | 93.2% | 90.4% | -2.8 | 95.57% |
| roban->roban | 93.2% | 90.0% | -3.2 | 95.42% |

G1 的退化覆盖走路、跑步和上身动作，主要失败类型为 body_z_termination。Human→G1 的 141 个失败中，112 条原本在 C 成功；仅 5 条 C 失败动作被 D 改善。配对家族 bootstrap 的成功率差值区间约为 [-26.70,-17.06] 个百分点，支持明确退化。完整逐路比较与区间见 `logs/v0.2/staged_run01/finetune_ppo/analysis_20261005/comparison.json`。

## 训练过程与诊断

- 所有训练日志数值有限，实际应用的 minibatch KL 最大约 0.019993，没有超出 0.02。这个约束是相对各轮采样策略的局部约束，不限制相对最初 C 的累计漂移。
- 预热末段到训练末段，G1 训练回合成功率由 96.84% 降至 90.56%，Roban 由 95.88% 降至 94.71%。随机训练起点统计弱于完整片段验证对累积误差的检验。
- critic 的解释方差上升，同时 actor 的奖励和成功率下降。价值拟合改善不能据此等同于策略改善。
- 固定 C 回放中的每机型 512 个状态，以同一输入替换模块，六路动作 MSE 均值：只换 D 主干 0.00708；只换 D 本体 Encoder+Decoder 0.01200；全部换 D 0.03212。仅本体 Encoder 为 0.00533，仅 Decoder 为 0.00497。源 Encoder 逐值未改变。
- 上述模块替换是动作敏感性诊断，不是闭环训练消融；MSE 不可直接相加或作为因果贡献比例。结果不支持忽略私有模块。
- 对冻结 D 最终策略采集三批新训练状态，每机型 96 环境 × 32 步，共 18,432 transitions；没有 optimizer step，参数逐值未变。共享主干上的跨机器人 PPO 梯度余弦为 0.00956、0.01303、0.00694，接近正交，未见强烈负相关。
- 同一次抽样中，权重 0.1 的 C 动作保持项主干梯度范数约为对应 PPO 梯度的 0.09%–0.24%。这是保持项较弱的直接证据；单次末态抽样不能证明全训练过程没有任务冲突，也不直接代表 Adam 预条件后的更新方向。

## 下一步建议（尚未执行）

1. 保留 C 作为主模型，D 归档为负对照；先评估 D 的早期 checkpoint（例如 150、200、300），判断是否曾短暂产生收益。使用固定分层动作子集筛选，再对候选做完整验证。
2. 从相同 C 权重或 actor 仍等于 C 的预热终点做短消融：全执行模块、冻结主干只训练本体/动作头、仅训练主干。其余采样、预算、噪声、KL 和保持项一致，每组先 100–200 次 PPO，定期做纯策略验证。
3. 将相对 C 的累计保持作为独立实验因素：增强/按梯度尺度校准保持项，或增加相对固定 C 的漂移约束。不要把局部 KL 通过当作整体能力保持。
4. 审计 critic 的任务条件信息和优势估计：现有 critic 输入为本体历史及当前目标误差，未显式读取来源命令窗口、来源标识或距动作结束的信息。是否因此引入不良优势方向需单独验证，不能直接认定为本轮根因。
5. 研究主线继续以 C 为基础，安排共享学生与独立学生的等每机型数据/采样预算对照，报告参数量与计算量；这比持续追求更高 D reward 更直接检验经验共享价值。

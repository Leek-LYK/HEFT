## B 的实际结果与阶段决策

B 完成 2,000 轮、65,536,000 transitions，冻结模块保持不变，PPO 更新为零。两机型完整验证各 500 条、83 个家族：

|---|---:|---:|
| 成功率 | 93.4% | 90.6% |
| 平均完成比例 | 96.8525% | 95.6949% |
| 恢复片段比例 | 0% | 0.4% |
| 根相对 MPKPE | 0.08403 m | 0.08929 m |
| 世界 MPKPE | 0.86896 m | 0.92615 m |

原 `student_human/eval_val/` 保留相对教师门槛下的未通过结果：成功率下降和根相对误差增量超限，世界误差为诊断。

按本轮用户认可的能力优先计划，独立 C 配置 `cfg/xwbc/v02/source_adaptation.yaml` 增加 `acceptance.stage_b_absolute`：B 准入要求两路成功率 ≥90%、完成比例 ≥95%、恢复片段 ≤1%、根相对 MPKPE ≤0.10 m。原教师相对退化写入诊断，所有评分保持原值；新门槛结果在 `student_human/eval_val_capability/`，绑定原报告摘要、逐片段结果及最终权重。这里没有重跑评估或修改旧评分。

该设置只用于 B→C 准入。C 的六组合继续相对 B 的 Human 路径验收：成功率/完成比例最多下降 5 个百分点、根相对 MPKPE 最多增加 0.02 m、恢复片段 ≤1%；世界误差增量保持诊断。没有新设置的历史配置保留原规则。

## C 的训练范围与预算

- 从 B `checkpoint_final.pt` 加载完整学生；G1/Roban 命令编码器沿用 B 中未训练的初始化权重，从本阶段开始学习。
- 仅训练两个机器人来源命令编码器。Human 编码器、本体编码器、共享主干、动作头、critic、策略标准差全部冻结。
- 同一配对窗口的原始 token MSE + 同一实际目标状态的 Human 动作均值 MSE，权重均为 1；不使用 PPO。
- 每机型 1,024 环境，16 步 rollout，2,000 轮；总计 65,536,000 transitions。
- 每轮 32 次监督优化，每机型 batch size 2,048；Adam，学习率 1e-4。
- 每机型 32,768 行均匀 reservoir，实际访问状态持续查询冻结 Human 路径。
- Human 接管概率前 300 轮降至零，第 301 轮起纯新来源执行；监督查询持续进行。
- 每 250 轮保存 checkpoint 并校验冻结摘要。训练结束自动运行 500 条验证动作 × 六组合；D 后续按结果决定。

## 验证与复现

16 项分阶段 CPU 回归通过，覆盖旧门槛兼容、B 绝对准入、完整性/有限性/恢复/姿态要求、C 不受 B 绝对准入开关放宽，以及已有冻结与监督检查。

`stage_c_preparation/reassess_student.py` 基于实际 B 权重在 CPU 上独立计算 C 冻结模块摘要。正式启动后将其与 C 的 `frozen_modules.json` 核对，确保使用正确 Human 基线。

## 启动后核验

北京时间 2026-10-04T13:07:02.762067+08:00 启动；后台会话 PID 为 3384239。检查时已完成 3 / 2,000 轮，累计 98304 transitions，已写入指标均为有限值。C 初始冻结模块摘要与独立从 B 最终权重计算的摘要一致，可训练参数仅属于 G1/Roban 命令编码器。TensorBoard 6008 已实际显示 `source_encoders/tensorboard` 的 token/action MSE。

C 日志中的每机型 `token_mse` 和 `action_mse` 分别累加 G1、Roban 两个来源的损失；B 的动作损失只含 Human 来源，两阶段数值不直接等值比较。`visited_state_action_mse` 使用当前实际选择的新来源与 Human 路径比较。

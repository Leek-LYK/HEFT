# A→B→E：去除 C 的等预算路线消融

日期：2026-10-05（北京时间）。用户授权规划并启动正式训练。原 A/B/C/E 权重及评分保留，实验输出独立保存。

## 问题与假设

在相同 B 后续采样与优化预算下，直接对六路施加原生 Teacher 监督，能否替代 C 的来源适配，再达到现有 A→B→C→E 的跟踪能力？本轮比较完整路线，不能分离 C 的 token 对齐、接管课程、编码器初始化与保持目标各自的因果贡献。

固定使用 `logs/v0.2/staged_run01/student_human/checkpoint_final.pt` 的 B 权重及同一组 A 教师。不重跑 B；B 中未训练的 G1/Roban 来源编码器原样加载。初始化新 Adam 和空 reservoir，属于 B 权重初始化的新阶段，不是恢复 B 优化器。

## 方法

全程采用 E 的六路教师动作监督，`train_sources: true`：更新三来源编码器、本体编码器、共享主干与动作头；critic、标准差和教师冻结。学生独立执行，教师接管和 PPO 更新均为零。

每个实际访问状态查询对应执行机型的原生特权 Teacher，并对三种配对来源等权监督。保持项使用冻结的起始 B，在同一状态、同一来源上的动作：`MSE(student, teacher) + 0.1 * MSE(student, frozen_B)`。有效动作维度、来源、机型依次等权。没有 C/E 权重、token 或动作参与训练。现有最终 E 的完整验证分数仅作为评估参考元数据。

选择保持同一“冻结起始模型”的规则，避免另行改变保持项权重；代价是 B 未训练机器人来源的保持目标可能限制学习。负结果只能说明当前直接 E 配方的表现，不能证明所有无 C 方法均不可行。

Adam 学习率全程 1e-5，梯度裁剪 1；每机型 1024 环境、rollout 16 步、32768 行独立 reservoir；seed 0。保留 E 的来源均衡采样、环境、控制、数据和时序上下文。

双方 B 后续合计 2300 轮、75,366,400 transitions、68,800 次 optimizer.step、271,974,400 次回放状态抽样（两机型合计，含重复抽样）。计数逐轮记录，并在完成后独立审计。A/B 为共同成本；先前方法探索和本轮工程短检查另计。C 与 E 的可训练参数、来源损失项及教师查询不同，因此不是等 FLOPs、等标签数或等墙钟实验。

前后两段仅改变优化次数与 batch，始终是 E 的目标及可训练模块；不执行 C，不在第2000轮重置 Adam 或 reservoir。学习率不采用 C 的1e-4，保持现有 E 配方的1e-5。

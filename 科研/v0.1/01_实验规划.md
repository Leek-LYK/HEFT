# v0.1：小数据跨来源、跨机型动作跟踪实验规划

更新日期：2026-10-01。分支：`research/xwbc/v0.1`。遵循 [长期研究规范](../../.SKILL/SKILL.md)。

本阶段先回答：同源配对数据能否帮助共享策略理解人体、G1、Roban 三种命令，并在 G1 与 Roban 上形成有效跟踪？采用约一万条动作的候选池，逐级从数据验证、小集合闭环走向方法比较。

本文件保留规划阶段的研究假设。后续用户已授权实现正式实验，并明确取消负载与固定三阶段；当前实现采用无负载直接 PPO，已生成正式数据及运行脚本并完成有限预算验证。最新可执行设置见 [正式实验使用说明](../../docs/xwbc正式实验.md)，实测见 [实现与验证记录](03_正式实验实现与验证.md)。下述尚未采用的结构与预算作为后续对照候选。

## 1. 研究问题与实验假设

| 问题 | 假设 | 主要比较 |
|---|---|---|
| 跨来源命令能否表达相同意图？ | 配对监督使来源编码器形成兼容表征 | 同一目标机器人上切换 Human/G1/Roban 命令 |
| 共享策略是否改善经验利用？ | 两种机型共同优化主干，有助于相同训练量下的跟踪表现 | 架构匹配的独立策略与共享策略 |
| 命令对齐是否有效？ | 表征对齐降低来源切换造成的性能差异 | 有/无对齐损失 |
| 时序结构是否值得引入？ | 时序主干改善相位理解与稳定性 | 等历史信息的 MLP 与 Transformer；列出参数量和运行开销 |

主结果为三种来源与两种执行机型的六组合矩阵。共享主体、来源编码器和目标机型适配层作为一个模型包保存；评估切换路由时保持权重冻结。

## 2. 数据池：一万条是配对动作总量

一个样本标识关联人体、G1、Roban 三份表示；一万条表示一万个配对动作，而非三个来源文件数量之和。候选总量划为训练 8,000、验证 1,000、测试 1,000。

已生成 [候选清单](../../logs/v0.1/planning_20261001/candidate_manifest.jsonl)，只保存路径和分组信息，不复制或修改源动作。它是待接入和质量审计的数据候选池，后续转换结果另行版本化。

### 家族划分与复现

当前采用保守命名规则：取文件名 `__` 前部分，去掉末尾数字编号并忽略大小写；跨表演者、镜像、录制日期及类别统一分组。这样把相关录制及变体放在同一集合，形成 3,707 个候选家族。这里的 family 是命名代理，接入元数据后核对其含义并记录合并关系。

先按家族划分全集，再在各 split/category 内按家族轮转取样，优先覆盖不同家族。使用 SHA-256 确定顺序；按预先指定配额，从种子序列中取首个满足容量的划分，得到种子 31。该选择仅使用文件名和数量。候选清单摘要及生成脚本保存在本轮日志中。

训练/验证/测试分别包含 2,985/348/374 个不同家族，跨集合家族交集为零。杂技的家族覆盖为 8/1/1，逐类报告同时展示家族数；其结果优先用于案例分析。测试集合仅用于最终冻结模型评估；当前对少量测试文件的格式与几何检查属于数据接入检查，不用于调参。

选中数据后检查配对、时序、数值和可行性。源数据保留不变，记录每个目标机型的有效性标签；主比较使用统一、预先冻结的共同有效集合，机型特有动作另报覆盖率。候选发生剔除时优先从同一 split/category 确定性补选，并发布新的 manifest。避免把旧 Roban 的单机型筛选直接当成跨机型共同标准。

完整实测见 [小批次检查记录](02_小批次检查记录.md)。此次抽取 60 组三元组，每类 10 组，完成全片格式/finite 检查及每片抽帧的 Roban CPU FK 对照。

| 接入项 | v0.1 处理方案 |
|---|---|

| G1 命令及参考 | 按 CSV 列名映射关节，使用已查阅的 BONES-SEED 单位和旋转约定转换；在当前 G1 资产上做 FK 与动作可视化检查。 |
| Roban 命令及参考 | 复用源关节契约，重排到策略顺序；依据当前训练资产生成参考 body 位姿。 |
| 头手参考点 | 源 Roban 头部与当前模型存在固定原点差，源腕部与手球原点也不同。以当前目标资产 FK 统一奖励/评测参考，保留源坐标和变换说明。 |
| 配对加载 | 显式使用 motion_id、frame_index、source_type、target_robot；同一时间索引分别取命令和目标参考。 |

本轮测得源 `zarm_l5/r5` 位于前臂局部约 `[0,0,-0.2085]` 米，当前 handball 原点位于 `[0,0,-0.085236]` 米，差为约 0.123264 米。源 `zhead_2_link` 相对当前同名原点沿局部 Z 约偏移 -0.026453 米。其余共同 body 的抽样 FK 位置最大误差约为微米量级。这些结果使后续关键点定义有了直接依据。

第一版优先用当前资产 FK 统一机器人命令和目标参考，不依靠旧手部名称别名。需要计算偏移点速度时使用相应刚体运动关系，确保位置、姿态和速度描述的是同一参考点。

先转换小集合，再处理一万条候选。全量数据张量放在 CPU，按训练窗口传入设备；在扩展前测量实际帧数、内存、初始化耗时及吞吐，用实测决定缓存配置。

## 4. 首版模型与学习路线

### 输入与路由

使用三个命令编码器 `E_human/E_g1/E_roban`，两个本体状态编码器 `P_g1/P_roban`，一个共享主体 `B`，两个动作头 `D_g1/D_roban`：

`action = D_target(B(E_source(command_window), P_target(proprio_history)))`

来源决定命令编码器，执行对象决定本体状态编码器与动作头。机器人命令以 FK 得到的空间特征为主，人体命令使用已有骨架特征。不同来源可以具有不同输入维度，通过编码器输出同维 token。

首版候选 token 维度为 128，共享 MLP 隐层为 `[512,512,256]`。先保持这些规模固定，研究共享与对齐的作用；模型规模搜索放到闭环稳定之后。

命令窗口拟用当前帧及过去/未来各两个参考时刻，偏移为 `[-4,-2,0,2,4]` 个数据帧；本体状态拟用最近 8 个控制步。边界采用显式有效帧掩码，统一各来源的时间窗口。MLP 与后续时序对照使用相同可见时间范围，离线方案记录实际前瞻时长。

命令空间特征以来源骨盆位置与水平朝向为归一化依据，保留根高度、根速度及相对片段初始朝向，避免丢失转向意图；仿真浮动根单独处理。坐标转换和初始朝向对齐在接入说明中固定，各来源使用一致的语义规则。统计归一化仅用训练集合拟合，验证与测试冻结统计量。

actor 读取选定来源命令和目标机器人本体状态。目标机器人同源参考用于 reset、奖励、终止与特权 critic；跨来源 actor 输入在接口层显式列出，不附加目标参考关节观测。现有 HEFT 的目标关节观测需要在新路径中替换。

### 优化与训练组织

先实现非对称 actor-critic 的直接 PPO：actor 输入可部署信息，critic 可使用目标参考与仿真特权量。现有 HEFT Teacher/Adapt/Finetune 保留为工程基线和后续蒸馏路线，首轮对照采用相同的直接学习设置，减少阶段差异。

两个同构机型环境池分别采集 rollout，以相同数量的 transition 共同更新共享参数。首版采用单进程组织两个环境池，分别计算合法动作空间上的 PPO 概率和损失，再等权汇总；保留各自 critic、奖励统计和归一化。状态接口可使用 padding，概率、熵和 KL 只统计有效动作维度。

每个 episode 均匀选择三种来源之一，episode 内保持来源不变。表征对齐使用同一动作、同一参考窗口的三种编码，对归一化 token 做配对 MSE，与 PPO 联合优化。初始对齐权重拟为 1；同时记录 token 方差、跨样本距离、检索准确率和梯度尺度，检验表征是否保留动作差异。

短训练先采用共享对照配置：Adam、学习率 1e-4、clip 0.2、3 个 PPO epoch、4 个 minibatch，折扣与 GAE 延用基础实现。动作缩放、PD 和关节边界沿用机型配置。与 HEFT 原始优化器及超参数的差异单独记账，主结论以架构匹配实验为依据。

基础奖励与终止逻辑先保持一致的任务含义，适配头手参考点。短闭环阶段先固定平地，关闭外力扰动和命令噪声等额外随机因素；后续以共同配置逐项恢复。记录实际课程进度，避免短训练停留在不同的课程阶段。

## 7. 评测与阶段决策

对同一冻结模型执行六组合。相同目标机型使用相同片段、初态、地形和终止规则，只切换命令来源。默认确定性动作、固定评估种子、无训练扰动；记录初始化所用目标参考和朝向对齐。

主要指标为完整片段成功率、平均完成比例、目标机型语义关键点位置误差、根姿态误差和速度误差。位置指标同时区分世界坐标轨迹误差与根相对姿态误差；误差统计包含提前终止前的有效步数，与完成率一起解读。

成功定义为在预定失败条件触发前走完整个评估片段；仿真非有限状态计为失败事件。边界完成优先于相同控制步上的时限截断。保存跌倒、跟踪偏差、关节边界和数值事件等分类，避免将正常结束并入失败。

先在训练/验证上冻结六组合评分实现、关键点集合和终止阈值，再使用测试集。头手评分采用当前目标资产的一致原点。主报告包含逐来源、逐机型、逐类别和类别等权汇总；置信区间按动作家族聚合，避免把同一家族的多个变体当成独立样本。

阶段决策依据：

- S1：所有输入输出契约和六种路由可运行，reset 后历史正确清空，动作在对应机型合法维度内。
- S2：有限的损失和梯度、两个机型共享模块更新可观测、每种来源参与训练、checkpoint 重载前后确定性输出一致。
- S3：相对初始化，训练子集的完成度和跟踪指标呈学习趋势；验证集逐格可解释，失败集中于可定位的动作或接口问题。
- 正式阶段：在 S3 之后根据独立基线确定最小有意义收益和允许退化范围，提前写入评估协议。用家族级统计比较方法，不预设短训练的绝对成功率承诺。

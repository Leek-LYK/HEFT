# 01 研究问题与总体方案

## 研究定位

RefineTrack-TS v0.1研究：同一clean意图产生的joint参考错误，能否通过已有HEFT privileged control representation与部署反馈推断得到补偿。测试的是闭环控制，非motion reconstruction。对hold/offset等不可辨识情况，history不能保证恢复唯一clean意图，Teacher不是可实现性能的必然上界。

当前HEFT本身已具备privileged motion guidance、paired clean/raw和三阶段学习。本版的价值应来自**Roban统计标定的污染、严格信息隔离、公平对照、clean能力保留和真实rollout证据**，不能把原有Adapter改名当作新架构贡献。此判断基于本仓库，不是其他fork/论文参数。

假设：H1旧部署Student随dirty强度退化；H2普通noisy RL可恢复部分性能；H3 clean privileged guidance在相同预算/物理条件下进一步改善Teacher；H4 Adapter能把主要收益转到仅raw/history的Student；H5冻结Adapter的现有Finetune能缩小控制gap而不压制clean动作。均待实验，不预写正结果。

## 最小主方案

保留21动作、policy1313、priv4270、critic90额外domain字段、latent40、Actor/Adapter MLP、Student量化器、PPO/GAE/DDP与控制链。Teacher Actor仍看raw policy输入，encoder_priv仍看clean目标和simulator状态；Stage2用Student rollout估计Teacher latent；Stage3先按现有冻结Adapter方案做PPO。

先只joint corruption+nominal physics，不引入payload、push、rough terrain、friction变化、root corruption、torque action、新backbone或生成模型。第一版不新增Actor observation；可在诊断证明现有输入不足后另立版本，不在本轮顺手增加clean/raw residual通道。

## 对照体系

| ID | 模型 | 用途 |
|---|---|---|
| B0 | 原最终Student，不训练 | 保留成功基线；测S0/S1/S2/S3退化。注明历史已含噪声/DR |
| B0-T / B0-A | 原Teacher/Adapt | 历史阶段诊断，不作新算法公平计算预算对照 |
| C | B0在S0+nominal继续PPO | 排除额外训练/nominal适应本身的收益 |
| N-direct | B0在S0/S1/S2上普通noisy PPO，无Teacher监督 | 强部署对照：允许Actor+Adapter共同PPO更新，量化器STE，不强制冻结未适应新噪声的Adapter |
| N-raw-T/A/F | 同原Teacher起点、同三阶段预算；encoder只能看raw-derived目标+同样sim状态 | 同容量clean-guidance消融；reward/critic可用clean训练信号 |
| T / A / F | RefineTrack新Teacher / Adapt / Finetune | 主三阶段链 |

C和N-direct共用同一可部署网络与优化选项，预算分别匹配，C不能只给极小预算。N-direct与F按**新增总环境transition预算**匹配并报告实际更新次数和墙钟；不是只让N-direct跑Stage3预算。T对N-raw-T比较同Stage1预算；F对N-raw-F比较整链；F对N-direct比较更强部署结果。N-direct若联合更新不稳定，可比较冻结Adapter版本，但同等验证调参预算、按validation选优，不能只保留弱版本。N-raw和T继承共同历史Teacher（历史clean先验共同存在），所隔离的是本轮新增clean guidance，不宣称从未用过privileged learning。

N-raw不能把teacher_mem_path直接改成dirty：那会让reward/termination也追dirty，制造弱对照。需要单独路由encoder的reference source；clean reward/critic继续保留。所有raw派生目标（FK、q差、contact、termination hint）必须重算；不允许只改target_joint_pos而留下clean keypoint或hint泄漏。原critic的clean priv需独立保留，encoder可从独立同shape `encoder_priv_obs`读取；这只在N-raw支路需要，T/A/F部署不新增输入。

预计约5–6个现有Python文件可选分支改动，新增约4–6个脚本/公共工具、1套profile overlay与阶段exp、约4组针对性测试。该范围是代码审计后的规划，不是已完成的patch或工时承诺。只做T/A/F数据通路时不用改Actor；完整科研对照与可信评测才是主要开发量。

clip-before-FK：旧实现的q clamp发生于FK之后，已查到源样本越界。推荐v0.1显式先按真实joint limits规范化clean/raw q、然后FK/差分，所有比较模型使用相同模式；旧目录与默认模式保留。此举会改变少数clean body targets，须先对B0做legacy-vs-consistent S0桥接评测并冻结说明，不把这一收益归给TS。若桥接差异不可忽略，先解决/拆分实验，禁止静默混用两套目标。

## 实施顺序

1. 合并本轮事实与合同草案；不启动训练。
2. 家族split/ID映射、joint-limit一致性审计、train-only corruption标定；建立独立数据目录。
3. nominal effective config、pair/information/gradient/export测试；以S0证明两路等价，strict load必须通过。
4. 有界单进程和DDP smoke；B0重复评价量化自然波动，完成reference污染效果检查。
5. 冻结数据/seed/预算/评价合同。先N-direct与T/N-raw-T pilot，再正式对照链；依据validation选checkpoint。
6. 一次性解封test，归档结论与局限。正式模型、大日志继续在dataset/_audit下；科研仅保留结果摘要和provenance。

正式run目录建议 `dataset/_audit/roban_ominisoma/refinetrack_v01/<arm>_s<seed>_<timestamp>/{train,adapt,finetune}`；数据 `dataset/roban/refinetrack_v01/`。本轮未创建这些大产物目录。

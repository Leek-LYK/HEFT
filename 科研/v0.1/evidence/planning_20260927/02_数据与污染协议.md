## 1. Clean source 与 split

唯一基础clean source：`dataset/roban/main/train_50000_v1`，45,213有效段、45,198源、18,026,422帧、50Hz。元数据/张量hash见[provenance](evidence/provenance.json)。不覆盖源NPZ、memmap或labels。六类full集不是本版默认替换。

新split以source family为单位，禁止同一源不同segment、镜像/近重复变体跨split。先建立family_manifest：原source path、文件hash、segment_start/end、原motion_id、人工可审阅family_id、分配原因。镜像命名不能仅靠猜正则；至少归并同源与已证实镜像，再做内容近重复候选核验；不确定家族放同侧或暂时排除并计数。

建议split seed=20260927，SHA256(`split-v1|seed|family_id`)前8byte无符号big-endian除2^64，<.8 train、[.8,.9) validation、其余test。80/10/10是数据分配方案，不是性能验收百分比。按motion长度、速度、活动幅度报告分布；若需分层必须在freeze前写死规则。实际计数/清单/hash目前null，不能根据45213直接向下取整伪造。

**这些validation/test属于本轮继续训练held-out，不属于基础模型pretraining-unseen**：旧Teacher可用全50K且历史覆盖未逐ID恢复，按可能见过处理。v0.1主结论是已有motion source上的新污染鲁棒性迁移。若要声称新motion泛化，另从50K之外同main域建立source/family去重的external test，不能用full目录名字证明无交集；其构建和标签本轮未完成，不阻止明确限定的主问题。

所有新模型使用同一split和resample_on_reset=true，跟踪unique family/motion覆盖；B0本身不重训。源clean reset/reference frame与raw一一对应；skip_initial_frames=5同时应用两侧，所有污染事件frame_id记录为**未trim源segment内索引**，运行时显式+5。

## 2. 配对形式与加载

优先 **离线、确定性、minimal memdataset pairs**：当前已有teacher_mem_path/student_mem_path与双cache，首版无需新在线随机生成框架。train先固定少量seed变体/每motion，S0/S1/S2等权采样；资源评估后冻结变体数（建议2），通过shard组权重使每motion总权重相同，不让变体多的motion被超采样。S0可不配student_path，回退同clean cache；同时保留S0显式双路径用于等价测试。

布局建议（尚未生成）：

```text
dataset/roban/refinetrack_v01/
  split_manifest.json
  train/clean/shard_000/...
  train/raw/<type>_<severity>_<replica>/shard_000/...
  validation/{clean,raw}/...
  test/{clean,raw}/...
  corruption_manifest.jsonl
  dataset_groups.json
  full_report.json
```

每个pair有stable `pair_id=(source_sha256,segment_start,segment_end)`、旧motion_id、新local_id、family/split、fps50、length、joint_order、root_hash。clean与raw `starts/ends`相同；frame t永远对应同一clean t。hold只冻结joint内容，不冻结episode/root时钟。root position/quaternion逐元素相同；root velocity由同root差分应相同。q为rad、wxyz、胸部root，腰不翻号。

直接从已过滤有效段写raw，**不对dirty重新执行clean质量过滤并丢弃困难样本**；只拒绝schema/非有限/构建失败。raw速度/body由当前资产FK差分重建，不复制clean velocity/body。保留raw生成前后和runtime实际输入的幅值、clamp比例。旧loader只按index/length配对，新preflight必须检查ID与root/fps；同长度错motion必须hard fail。

推荐v0.1 canonicalization先将两侧q按真实MJCF范围裁剪，再统一FK；原source保留，canonical clean单独派生且记录逐joint改变量。先完成01规定的S0桥接，后续统计/污染均用这一有效clean；避免“q来自clamp后、body来自clamp前”的混合target。S0定义为raw=canonical clean逐元素一致。

离线cache方便全帧连续、顺序无关和test复现；代价是CPU全量加载与磁盘膨胀。一个基础tensor集约0.94GiB FP16，raw变体按副本线性增加；运行转FP32且每DDP rank独立加载。不能一次配置所有8类型×3强度×多副本全量进入每rank。pilot先有界shard/少量实例，正式冻结每motion混合事件而非为每类型复制全50K；evaluation分类型分批加载。未来在线生成可放cache refill前，必须以absolute frame/stateless seed生成整条确定性流、保留相关噪声状态，不能每次13帧horizon重新抽独立错误。

## 4. 污染定义与S0–S3候选

逐joint定义 `d_j=P95(|q[t+1]-q[t]|)`、`a_j=median_motion(P95(q)-P05(q))`，基于train统计。使用左右同型关节pool尺度以兼容symmetry，记录pool前后值。近静止关节用同组非零尺度；整组静止则不凭空设幅值、记录inactive。

候选参考尺度 `A_j(s)=k_s*d_j`，k(S1,S2,S3)=(.5,1,2)。这不是通过率硬门槛。示例waist≈(.0216,.0432,.0864)rad、knee≈(.0578,.1156,.2313)rad，最终逐joint值待train-only统计。统一将基础随机向量归一化到指定RMS，Gaussian事件峰值裁3A，最终物理范围clamp；保存实现后RMS/P95/peak而不是只报名义severity。

时间基准 `W_group=round(median_j(a_j/d_j))` 帧、至少1帧；由上表估计约waist9、hip8、knee5、ankle5、arm8帧，只是初始候选。S1/S2/S3事件持续(W,2W,4W)，drift/correlated使用更长平滑窗；所有事件限定motion内且记录实际截短长度。长窗上限为可用motion帧的1/4（候选），避免对短片全程污染。hold的误差不由A直接控制，须按hold时长报告实际q偏差，并据train统计分档；不能声称所有类型的S2有完全相同RMS。

| 类型 | joint-only定义 | 建议训练/评价角色 |
|---|---|---|
| jitter | 逐绝对frame独立、零均值扰动，幅值按A；事件内全时间一致可重放 | train S1/S2；eval S1/S2/S3 |
| offset | 随机符号/向量常量偏差，持续事件窗 | 同上 |
| burst | window内jitter加平滑包络，window外0 | 同上 |
| correlated noise | 同group共享噪声+joint独立残差，时间AR(1)，tau由W；组共模/反模分开 | 同上 |
| jump | 在某frame阶跃到偏差，保持后恢复；root无跳变 | held-out type评价 |
| drift | joint偏差缓慢线性或低频变化，幅值A、时间窗明确 | held-out type评价 |
| hold | 保持q_raw[t0]，持续L后接回当时clean；不重定时root | held-out type评价 |
| seam | 当前motion相邻joint片段拼接造成不连续，root仍来自原时钟 | held-out type评价 |

S0只clean；S1 mild/S2 medium用于训练与validation；S3 strong为最终stress，不用于checkpoint选择。首版训练先单类型事件和一个group，S0/S1/S2建议等权；多group/多事件同时叠加单列stress，不能混进主分布。held-out types不用于调参，性能只支持这些人工错误上的泛化；不能等同真实planner误差鲁棒性。seam不跨split借别的motion，优先同motion错帧片段，记录donor frame与接缝；若以后跨motion，donor必须同split。

joint groups使用真实21关节：waist、左右hip、左右knee、左右ankle、左右arm；均衡抽组与左右，镜像实验变换raw和clean一致。第一版不污染root任何字段、不污染sim state、不丢帧/改fps/改motion duration。

## 5. 可复现性与验收

seed分域：split=20260927；训练run建议[0,1,2]；corruption(train,validation,test)分别以字符串域隔离，不依赖Python hash或env/rank编号。推荐PCG64+显式numpy版本；每实例seed=SHA256(protocol_version|split|pair_id|type|severity|replica|master_seed)前8byte big-endian。manifest保存seed、完整事件参数、算法版本、generator commit、train-stat hash、tensor/root hash、dtype、clip率。

重复生成需字节hash一致；单env/不同batch/不同cache窗口读取同frame必须一致；reset/rewind不可意外换test corruption；禁止通过全局torch RNG顺序决定val/test。数据hash、split hash与generator hash一并freeze。

preflight：来源未变、split family互斥、paired ID/length/order/fps一致、root完全相同、S0相同、所有finite、FK与有效q一致、污染前后差异与分档相符、旧噪声enable=false、invalid motion不可静默跳过。未过这些检查，不开始正式训练。本轮只完成描述性统计与源hash核验，未生成paired训练集或冻结split。

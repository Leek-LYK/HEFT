# 05 评价与验收协议

## 1. 先建立共同evaluator

复用现有metric数学与控制接口，新增本地checkpoint/phase/paired-manifest驱动的统一runner。现有Teacher evaluator不是遍历式benchmark，brain evaluator绑定旧路径与成功子集；不可直接将两者输出拼表声称公平。

主层使用mjlab训练控制链、nominal physics、固定50Hz/200Hz、mean action、frozen VecNorm、同资产/目标预处理/初态。显式选择T或Student模块，不依赖含糊phase猜测；Student的Teacher模块仅用于离线诊断。第二层用既有官方AMP→HEFT控制链、500Hz物理/50Hz推理做部署兼容性复核，独立表格，不合并两层成绩。

逐motion完整窗口，从同clean frame开始，经过skip5后计数；结束包含源有效末帧，runner须核实before_update的t+1时序。超过现有max_episode_length1000的motion，评测放宽cap到所需长度，或预先固定window并明确“window completion”；不得20秒截断自动算整motion成功。参考XY超15m触发的原截断应单列protocol censoring，并通过预定义窗口/override解决，不能算跌倒或默默删除。reset clean姿态+lift/扰动是一种benchmark条件，固定初始化manifest；另外共同站姿启动评价只作独立条件。

采样在每个policy tick约定同一物理积分相位，记录frame_id、actual/clean/raw、dt、动作和done原因；终止状态必须在reset前采集。invalid输入/未起播/非有限恢复保留case，不补零、不只留下成功者。

## 3. Closed-loop task performance：最高优先级

- success：按预先有效窗口完成，期间无task failure/nonfinite recovery；如果同时timeout和failure，失败优先。分母=所有计划case，case是motion×corruption实例×init seed。
- early termination / task failure：逐原因计数，高度偏差、gravity偏差、非有限、无法启动、协议截断分开；“高度相对目标失败”不自动等同物理fall。沿用真实termination并额外标记明确fall事件。
- completion fraction=已播放有效帧数/计划有效帧数，遇失败不重新reset续播凑完成；记录首次failure时间、事件次数/分钟、failure前后污染发生时间。
- 原terminal_count含motion正常结束，不作fail rate。训练中随机起点短回合的motion_timeout比例不等于从头播放success。

brain部署层沿用原胸高<0.4m/qpos nonfinite等停止条件，不把此阈值当成训练层高度差阈值。

## 4. Tracking accuracy：所有目标对clean

不对dirty q算主tracking分数；另报dirty-clean输入偏差作为刺激强度。复用现有数学，不以reward proxy替代误差。

| 指标 | 约定 |
|---|---|
| Joint RMSE | 每帧sqrt(mean21((q_actual−q_clean)^2))，再时间均值，rad及deg；直接相减，沿用现有实现 |
| joint MAE/velocity MAE | 同reward误差定义，可帮助解释reward与RMSE差别 |
| Root-relative Body Pos | 各自R_root.T(p_body−p_root)，14 body平均欧氏距离，mm；同既有brain脚本 |
| Root-relative Body Ori | 各自R_root.T R_body的最短相对旋转角，rad |
| keypoint position/orientation | 训练13 keypoints（14 body去掉waist_yaw_link），同reward坐标/误差，独立列名 |
| MPJPE命名 | 本项目测的是指定body frame/keypoints；可标`MPJPE-body14(root-relative)`，必须附14节点，不冒充21关节轴心MPJPE；与上面Body Pos同一值不重复造实现 |
| root world xyz/XY/z | 对origin/yaw一次对齐后的原clean路径计算，单位m；不能取Student滑动reward目标冒充global path |
| root orientation | quaternion最短geodesic angle，并辅以gravity倾角 |
| root linear/angular velocity | 沿用reward：实际和clean分别转各自root frame再做norm，m/s与rad/s；如加world版本另命名 |

14节点清单：waist_yaw_link、zhead_2_link、l/r_handball、zarm_l/r3_link、zarm_l/r4_link、leg_l/r1_link、leg_l/r4_link、leg_l/r6_link。根base_link不计。

Ominisoma有真实root路径时世界XY有意义；brain参考XY恒零时标N/A，使用root-relative/关节指标且另报实际位移，不称轨迹误差。root-relative消除全局旋转，不能单独证明直立/根朝向正确。

## 5. Control quality与clean保真

记录raw action、clipped/applied action、scaled q_target、actual torque/effort limits，按joint/group汇总：action rate均值/P95（明确sampled/clipped/applied来源）、motor target saturation、网络clip比例、torque达到实际名义limit比例、joint软/硬limit越界时间与幅值、feet contact与clean contact一致性、foot slip、异常高度/倾角事件。阈值来自实际joint limits/contact contract或既有termination，不随模型改变。

Clean所有模型都测：success、joint/body误差、快速动作子集、actual对clean的P95−P05 joint幅值比、速度RMS/峰值比、主要动作事件相位延迟。快速层在train数据按参考速度分位数定义并冻结。动作接近静止时幅值比设N/A不除近零。

phase通过预先固定的相关/事件匹配窗给出signed lag和相关度，必要时谱比较；**主误差始终按原时间戳，不用事后DTW/shift修正**。幅值缩小/速度降低/phase延迟即使success升高也需报告，不能称完整保留clean tracking。

## 6. Teacher–Student诊断

按03记录continuous MSE、valid normalized MSE、variance/有效秩、Q gap/level占用、同state mean-action与scaled target差、T/A/F独立rollout return与成功差。Stage1和Stage3 reward语义有差异，跨阶段gap用统一evaluation任务指标；若报告return须用统一重算reward或明确不同不可直接比。

Teacher在Student访问状态上标注latent，因此另区分Teacher-own-state与Student-state诊断；低MSE仅发生在易状态不构成transfer成功。与常值预测/逐维均值基线比较latent，但最终判断仍看rollout。

## 7. 自然波动、聚合与选模

先B0在固定case上重复运行检验数值重放；随后建议至少5个预定initial-state seed × 每case3个固定corruption replica，所有模型复用同一组。相同seed的完全确定性重跑不是新的独立样本；训练seed变异与eval初态/污染变异分开。

主要统计单位是motion/source family：先在motion内汇总时间和replica，再motion等权，给case数量、有效帧、mean/median/tail；不要长motion主导总均值。success保留全case分母。误差分别报各自成功集、共同成功集、所有case截断前误差（后者只作带存活时长的诊断）；共同成功集不能替代全case成功率。配对比较用相同motion/corruption/init，family-cluster bootstrap给95%区间，训练seed分层；不把相邻帧当独立样本。P95注明是frame/body元素pool、motion均值分布或case P95平均，三者不混用。

先用baseline不同重复块的差异和CI确定自然波动尺度，再冻结clean非劣容忍和最小可解释收益。若基线完全确定且重复差为0，也不能任意要求候选逐float完全相等，应结合motion间/seed间不确定性和数值容差；具体值在pilot后写入合同，不预设任意百分比。

判定顺序：数值/协议有效性 → clean保留 → dirty success/completion → accuracy/control quality → latent解释。收益跨seed稳定且超出测量不确定性才支持假设；CI宽则inconclusive，继续数据收集需新预声明预算。一次性test只做报告，不据test选择“最佳epoch”。

## 8. 验收前测试与结果文件

新增定向测试：pair错位/duplicate/source同family跨split拒绝；S0两路等价；root hash不变；cache重叠frame/rewind一致；no-clean-leak；阶段参数更新集合；normalizer状态；mean-action export roundtrip；提前失败/timeout重叠/未结束case统计正确；超过20秒motion与末帧时序。

run产物保存逐case manifest/summary、frame metrics、termination events和selected checkpoint index到原audit目录；科研只追加精简CSV/JSON汇总、关键图、hash路径和结论。已有tests本轮未运行（未修改训练代码），新增上述测试是实施要求，不伪称已通过。
